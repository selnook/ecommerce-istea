# E-commerce Modular

Proyecto de e-commerce desarrollado para la materia **Laboratorio de Aplicaciones Web Cliente** del ISTEA (Instituto Superior Tecnológico Empresarial Argentino).

## Funcionalidades

Consumo de productos desde FakeStore API
Búsqueda por nombre
Filtro por categoría
Carrito de compras con almacenamiento en localStorage
Eliminación de productos del carrito
Visualización del carrito mediante modal

## Tecnologías utilizadas

HTML5
CSS3
Bootstrap 5
JavaScript (ES Modules)
FakeStore API

## Estructura del proyecto

```text
/css/style.css
/js/api.js
/js/cards.js
/js/storage.js
/js/index.js
index.html
```

## Ejecución

Se recomienda ejecutar el proyecto mediante un servidor local (por ejemplo, Live Server).
